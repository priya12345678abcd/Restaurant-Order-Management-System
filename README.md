# Restaurant-Order-Management-System
SQL-based Restaurant Order Management System with 12 related tables, 5,000 records, relational database design and business analysis queries.
# 🍽️ Restaurant Order Management System – SQL Data Analytics

## 📌 Project Overview
This project focuses on analysing restaurant and food delivery operations using MySQL to solve real-world business problems and generate meaningful business insights.

The project covers customer behaviour, restaurant performance, menu analysis, order trends, payment operations, delivery performance, customer reviews and coupon effectiveness.

## 🗄️ Database Structure
The database consists of 12 relational tables:

- Customers
- Restaurants
- Categories
- Menu Items
- Orders
- Order Items
- Payments
- Delivery Partners
- Deliveries
- Reviews
- Coupons
- Coupon Usage

## 📈 Business Analysis Modules

### 1. Customer Analysis
- Customer distribution by city and area
- Active and inactive customer analysis
- Top customers by order value
- Customer ordering behaviour
- Customer loyalty points analysis
- Customer purchase frequency

### 2. Restaurant Analysis
- Restaurant-wise order performance
- Restaurant-wise revenue analysis
- Average order value per restaurant
- Top revenue-generating restaurants
- Restaurant ranking by revenue
- Restaurant revenue contribution percentage
- High-rated restaurants with low order volumes

### 3. Menu Analysis
- Vegetarian and non-vegetarian item analysis
- Most expensive and affordable food items
- Category-wise menu distribution
- Average food price by category
- Most ordered food items
- Food item sales quantity analysis
- Best-selling menu items

### 4. Order Analysis
- Total order volume analysis
- Order status distribution
- Daily and monthly order trends
- Delivered and cancelled order analysis
- Average order value
- High-value order identification
- Order trends by restaurant and customer

### 5. Payment Analysis
- Payment method distribution
- Total revenue by payment method
- Successful and pending payment analysis
- Refunded payment analysis
- Payment transaction status analysis
- Average payment amount

### 6. Delivery Analysis
- Delivery partner performance
- Average delivery time analysis
- Delivery distance analysis
- Delivery status distribution
- Fastest and slowest deliveries
- Partner-wise completed deliveries
- Delivery performance comparison

### 7. Review Analysis
- Average restaurant ratings
- Highest and lowest-rated restaurants
- Customer review distribution
- Rating-wise review analysis
- Positive and negative review analysis
- Restaurant performance based on ratings

### 8. Coupon & Discount Analysis
- Active and expired coupon analysis
- Coupon usage count
- Most-used coupon identification
- Total discount given
- Customer-wise coupon usage
- Coupon effectiveness analysis
- Discount contribution to orders
